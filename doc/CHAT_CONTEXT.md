# 聊天上下文与流式请求

手机入口为「设置 → 模型设置 → 上下文设置」；macOS 在设置页直接进入。预算存在 SQLite `settings.chat_context_window_tokens`，默认 32K，可选 8K、16K、32K、64K、128K、256K（1K = 1024）。无效或旧版本未保存的值回退到 32K。

## 发送规则

- 预算计入系统提示词、消息格式开销、历史消息附带的搜索来源、当前联网搜索证据，以及输出预留。未指定输出上限时预留 4096 Token；自动标题按其 64 Token 上限预留。预留不修改 OpenAI 兼容服务原有的输出上限配置。
- Token 数为本机保守估算，不是模型 tokenizer 的精确计数，也不会作为精确用量显示或落库。实际模型上下文限制和计费仍以服务商为准。
- 保留最近用户消息所在轮次，从新到旧加入完整轮次；达到预算后停止，得到连续的最近历史，不拼接跳过中间轮次的旧内容。系统提示词始终保留。
- 仅裁剪发送内容，不删除 SQLite 历史。生成期间省略了旧消息时，气泡会显示说明。当前消息、提示词或搜索证据本身过长时明确提示，不静默截断。
- 超限错误提供「调整上下文」「重试回复」「新对话」；重试仅在尚未保存助手回复时可用，复用原用户消息，不重复落库。不自动缩小预算或自动重发。

本次可配置预算针对 Flutter 手机与桌面聊天；手表原生独立请求和配置同步未扩展此设置。复用 `ModelApiClient` 的手机手表 worker 采用其默认预算。

## 正文读取与局部更新

- 回复正文、模型列表和错误正文的读取均有 120 秒空闲超时。计时在原始网络字节层，SSE 注释、心跳与未形成完整行的数据都会续期；不以是否出现可见回答计时。
- 空闲超时关闭连接，手机保留已收到的部分回复。该超时不标记为可安全自动重发，避免服务已处理请求时重复消费。
- OpenAI `[DONE]` 与 Claude `message_stop` 均结束读取，不继续等待服务关闭连接。
- 流式文本通过 `ValueNotifier` 仅更新生成中的气泡；开始、结束、错误与搜索状态等变化仍更新页面。列表沿用 Flutter 默认的绘制隔离，无重复包裹 `RepaintBoundary`。

## 验证

`flutter test` 包含上下文选择、两类协议请求、正文停滞、心跳、超限错误、局部更新、预算保存与恢复，以及翻译覆盖测试。翻译守卫使用 Dart AST 检查静态中文 `tr` 参数、iOS 行/分组等标题说明、文字控件和异常文案，并检查已知枚举标签；变量引用或插值文案仍需补充对应测试。

Android 本地集成验证：

```bash
flutter drive --driver=test_driver/android_ui.dart --target=integration_test/android_ui_smoke_test.dart -d emulator-5554
flutter drive --driver=test_driver/android_ui.dart --target=integration_test/chat_context_smoke_test.dart -d emulator-5554
```

第二项使用设备本机 HTTP 服务，验证超限提示、调低预算、重试、历史保留和用户消息不重复。测试只清理自己创建的服务及话题，并恢复原有设置；不清空或卸载应用。截图存于忽略的 `.dart_tool/android-ui-qa/`。本地接口证据不代表真实服务商或配对手表真机验证。
