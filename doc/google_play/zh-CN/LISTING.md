# Google Play 商店详情草稿（简体中文）

应用名称：AI Link

简短说明：连接自有 API，跨模型文字与语音聊天，并在 Wear OS 手表上继续提问

完整说明：

AI Link 是一款使用你自己 API Key 的多模型聊天应用。你可以选择常见模型服务商，也可以填写自定义 API 地址与模型 ID。当前支持 OpenAI 兼容 Chat Completions 和 Claude Messages 协议。

你可以建立多个话题，查看本地聊天历史，阅读 Markdown 回复，并为所有模型或单个模型设置提示词。文字聊天支持流式回复；模型列表可从服务端读取，也能手动输入模型 ID。

语音输入由你配置的语音模型转写为文字，可选择自动发送或确认后发送。回复可选择通过语音模型合成后播放。Wear OS 配套应用可在手机完成配置后按住说话、显示文字回复并可选播报；手表无法连接手机时，可使用自己的 Wi-Fi 或蜂窝网络请求已同步的服务配置。手表问答在重新连接后同步到手机本地会话列表。

API Key 保存在设备安全存储中。聊天记录与提示词保存在设备本地；请求直接发送到你配置的第三方 API 服务，不经过 AI Link 的中转服务器。使用第三方服务可能产生由其收取的费用，并受其服务条款与可用性约束。

目前不支持图片或文件上传，也不提供跨账号云同步。使用 Wear OS 功能需先在 Android 手机完成模型和语音服务配置。
