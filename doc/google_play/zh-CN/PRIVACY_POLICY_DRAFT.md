更新日期：2026 年 10 月 31 日

AI Link 是用户自行配置模型和语音服务 API 的客户端。应用目前不要求注册账号，不设自有聊天中转服务器。

## 本机存储

- API Key 保存在手机的系统安全存储中。手机向手表同步所选服务配置后，手表使用 Android Keystore 加密保存对应密钥。
- 服务名称、地址、模型 ID、提示词、话题标题和聊天正文保存在手机本地 SQLite；聊天正文与提示词在该数据库中未单独加密。
- 手表问答可先保存在手表应用私有存储，并在两端恢复连接后同步到手机本地聊天记录。手表上保存的离线问答不会因清空手机数据而自动删除。
- 录音和合成音频是请求与播放所需的临时文件，使用后删除。语音转写后的文字会按用户设置发送给文字模型，并作为聊天记录保存在本地。

## 第三方请求

当你获取模型列表、发送聊天内容、使用语音识别或合成时，应用会把完成请求所需的 API Key、上下文消息、提示词或录音/朗读文字，直接发送给你配置的第三方 API 地址。该服务商如何处理、保存和使用这些内容，取决于其政策与合同。请只配置你信任的服务地址，并在发送敏感信息前阅读其隐私政策。AI Link 不会将这些内容上传到自有中转服务器。

开启手机联网搜索后，当前问题作为查询词，连同搜索服务 API Key 直接发送到所选搜索服务。检索到的网页资料随后作为临时请求上下文发送给当前文本模型；来源链接、标题和摘录随助手回复保存在本机明文 SQLite 中。联网开关、所选搜索服务配置和密钥经配对通道自动同步到手表；搜索密钥在手机安全存储、Wear OS 的 Keystore 加密存储或 Apple Watch 的 Keychain 中保存。手表通过手机或自身网络执行相同的搜索后回答流程，问答中的来源链接随问答同步回手机。删除搜索服务同时删除其密钥，已有聊天的来源资料保留；清空手机全部本地数据时一并删除。搜索功能默认关闭；测试搜索会发送固定查询“Flutter”，可能产生费用，不保存配置。

Agent 默认关闭。开启后，在聊天中发送的任务、按独立预算选取的对话历史和附件、当前项目资料及执行所需的工具结果会发送至所选模型；模型生成的搜索词发送至默认搜索服务，公开网页读取直接连接目标网站。目标、执行记录、来源快照和成果文件以明文保存在本机。任务不会自动写入长期记忆；删除单个任务、关联对话或清空本地数据会删除对应任务记录和文件；单独删除任务保留聊天中的已交付回复，用户已导出的副本不受影响。

## 权限

麦克风权限用于你主动按住录音的语音输入；相机权限用于你主动扫描配置或 API Key 二维码；通知权限用于在 Android 上显示 Agent 任务在锁屏后仍在执行。网络权限用于请求你配置的模型与语音服务，以及手机和手表之间的数据同步。拒绝麦克风、相机或通知权限不影响文字聊天。

## 删除与联系

你可在应用中删除单个话题、单个服务，或在“设置 → 通用 → 数据与隐私”清空手机全部本地数据。卸载手表应用可清除手表端保存的数据。已发送至第三方服务的内容不受本机删除操作影响，如需删除其服务端数据，请联系对应服务商。
