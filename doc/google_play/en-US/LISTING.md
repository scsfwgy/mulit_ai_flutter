# Google Play store listing draft (English)

App name: AI Link

Short description: Bring your own AI API for text and voice chats on Android and Wear OS

Full description:

AI Link is a multi-model chat app for your own API keys. Choose a supported provider, or enter a custom API endpoint and model ID. It currently supports OpenAI-compatible Chat Completions and Claude Messages.

Create multiple conversations, read local chat history, view Markdown replies, and set a global prompt or a prompt for an individual model. Text replies stream as they arrive. You can fetch a provider's model list or enter a model ID manually.

For voice input, your chosen speech model transcribes recordings to text. You can send the transcription automatically or confirm it first. Optionally, a speech model can generate audio for a reply. The Wear OS companion app lets you hold to speak, read a text reply, and optionally hear it. After initial phone setup, the watch can use its own Wi-Fi or cellular connection when the phone is unavailable. Watch conversations sync to the phone's local history when they reconnect.

API keys are stored in device secure storage. Conversations and prompts are stored locally. Requests go directly to the third-party API you configure, without an AI Link relay server. Third-party services may charge fees and have their own terms and availability.

Image and file uploads and account-based cloud sync are not available yet. Wear OS features require initial setup on an Android phone.
