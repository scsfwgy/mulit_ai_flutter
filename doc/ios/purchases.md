# Apple 试用与永久解锁

应用免费安装。使用 Apple 非消耗型商品 `com.maxhall.ailink.trial_7_days` 主动领取 7 天全部功能试用；到期后可主动购买 `com.maxhall.ailink.permanent_unlock`。永久商品目标价格为美区 US$10、中国大陆 ¥70，客户端展示 StoreKit 的本地价格。没有自动续费或到期扣款；第三方 API 用量另计。

## 权益规则

- iPhone 原生购买控制器是唯一购买权益来源，负责 StoreKit 2 交易验证、领取、购买、恢复和退款。Apple Watch 不查询商品或交易，也不调用商店购买、恢复接口；仅通过配对设备的 WatchConnectivity 通道接收手机原生权益快照。该快照信任配对 iPhone 已完成的 StoreKit 验证，不声称由手表再次独立验证交易签名。Flutter 服务配置中的开关不能授予权益，iPhone 也不接收手表回传的授权。
- 领取、购买和恢复后的权益变化自动推送，手表启动、恢复前台、重连和「刷新购买权益」也会向手机请求最新快照。权益消息独立于服务配置、语言及配置同步请求 ID，更新 applicationContext 时保留其它字段。手表设置显示「7 天试用中」或「已永久解锁」。
- 手表在 Keychain 保存原生权益快照，永久解锁保持至手机同步新的撤销状态，不额外要求每日连接手机。试用的截止时间固定为手机原始领取时间加 604800 秒，手表使用实时配对手机消息中的已校验时间和 uptime 检查，不因刷新、重启或重新同步延长。旧消息不能覆盖新状态，手机退款/撤销验证后的同步会移除授权；手表离线期间保存最后收到的永久状态，重连后补同步。同一次设备开机内，Keychain 中的 uptime 锚点跨应用冷启动继续推进；设备重启后向手机获取新时间，手机暂时不可达时才尝试 HTTPS 校时，不影响永久解锁。
- 永久权益来自当前有效非消耗型交易；退款/撤销后移除。恢复购买调用 `AppStore.sync()`。
- 购买返回值与 `Transaction.updates` 中的已验证交易先交付权益，再结束交易；后续空查询不覆盖当前进程刚取得的有效交易。查询同时读取商品对应的 `Transaction.latest`，按购买及签名时间合并，同一笔交易的已签名撤销优先于旧购买记录。原生控制器将 StoreKit 已验证的交易元数据和 JWS 写入本机 Keychain，冷启动先恢复已交付权益，再合并已验证的历史、当前权益和最新交易。空查询不等于已签名撤销，不能抹掉已交付权益；退款记录持久化后，旧购买回调不能恢复授权。缓存依赖原生写入和 Keychain 隔离，不声称再次独立验签缓存 JWS，Flutter 或服务配置不能写入购买日志。购买账户及交易范围由 StoreKit 查询与签名验证负责，不另用 App 下载账户筛选内购交易。
- 原生刷新期间收到交易更新会重新查询；传给 Flutter 的状态带递增序号，旧回复不能覆盖新权益。恢复失败提示不会被后台刷新清掉；恢复超过 45 秒会结束界面等待并明确提示，商店查询超过 30 秒也会提示。超时不伪造购买、退款或成功结果，后续已验证通知仍可解锁。
- 试用从已验证历史中最早的试用 `originalPurchaseDate` 开始，持续 604800 秒。退款、重装、恢复购买不重新开始；保留领取历史以阻止重复试用。
- 手机首次建立试用时间或设备重启后向 `https://www.apple.com/library/test/success.html` 发起 HTTPS HEAD 请求，用响应日期（及缓存 Age）校时；运行期间用系统 uptime 推进，不用用户可修改的墙上时间。已校准的时间锚点和系统开机标识保存在 Keychain，应用进程重启不会丢失；不同设备开机标识不能复用旧锚点。手表收到实时权益回复后使用手机时间，无需再次联网校时；延迟的 applicationContext 不能重建时间锚点。请求不携带聊天、密钥或录音。校时失败时暂停试用请求，但仍可阅读历史、编辑配置及恢复/购买。永久解锁无需该校时请求。
- 权益不足时，文字、联网搜索、识别及朗读请求进入购买页；手表提示在手机领取/购买并刷新权益。Android、macOS 的现有免费行为不变，Apple 和 Google 权益不自动互通。
