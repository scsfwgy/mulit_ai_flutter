# Agent 首版

2026-10-31 实现并调整为聊天内执行。默认关闭，在「设置 → Agent → 开启 Agent」开启，开关下提示复杂任务、资料整理或生成文件时建议开启，普通问答通常无需开启；「更多 → 消息设置」显示状态，点击直接进入管理页。开启后手机/桌面聊天直接执行 Agent 任务；关闭时恢复普通聊天，手表问答沿用原有流程。

## 使用

1. 配置支持工具调用的文字模型；需要搜索时配置默认搜索服务。
2. 在当前聊天输入任务，直接沿用当前模型、项目、提示词与按预算选择的聊天历史；附件沿用普通聊天的协议发送。
3. 在原对话查看回复、执行卡片、执行记录、来源与请求生成的文件。卡片显示当前实际执行阶段、最近真实工具步骤、对应的恢复操作和成果文件；请求次数、上下文估算及整理说明保留在详情页。文件先显示内容预览，实际排版导出后查看；手机分享、桌面选择保存位置。
4. 暂停后，可从原对话执行卡片或任务记录手动继续。网络等临时问题提供继续入口；密钥错误直达原服务配置，上下文不足直达预算设置，明确不支持工具调用时返回原对话切换模型。修正配置后仍由用户手动继续，不自动发起请求。更换服务、地址、协议或模型后的重试创建新任务，保留旧记录，不重复插入用户消息。关闭 Agent 会暂停正在运行的任务，保留记录和文件；关闭时只能查看，不能执行。

模型使用当前服务的 API Key 直连；每项任务只使用所选服务与模型。服务被删除、更换地址或协议后拒绝继续旧任务，防止将旧资料默默发送到新服务。需要可用的应用购买/试用权限（适用平台）。

## 模型检查、补充要求与成果复用

- 管理页的「测试当前模型」由用户点击后发起，最多两次简短模型请求，可能产生少量费用。仅调用固定的无害探针并检查结果回传，不读取聊天、项目、文件或搜索，不创建任务。通过仅代表本次工具回合兼容；不保证复杂任务质量，也不自动开启 Agent。离开页面取消检查，模型调用阶段整体超时 35 秒，购买权限和服务地区限制沿用原规则。
- 未完成任务提供「补充要求 → 补充并继续」。每次最多 4000 字、累计最多 20000 字，保留原目标、已完成步骤、资料与文件。未执行的旧工具调用先写入配对的取消结果，再发送新要求；不会按旧计划直接执行。补充要求保存在任务记录并显示于卡片和详情，不重复插入原用户消息。上下文裁剪保留同一任务的原目标与追加要求，仍不足时暂停。
- 完成的回答及文件内容预览均提供「保存到项目笔记」。先选目标项目、检查并可编辑标题正文，再确认保存。复用项目知识的容量限制、事务与分段索引，保存后可被项目聊天检索；同一任务的同一成果在同一项目重复保存不会新建或覆盖旧笔记，原笔记已删除时可重建。知识库保存 Markdown 原文并使用 `.md` 名称，CSV 来源使用 `.csv`；不会把文本标为 PDF、DOCX 或 XLSX。预览页即显示文本后缀；重新保存旧条目时纠正其后缀，不覆盖原正文。删除任务或原对话保留用户已确认的笔记。
- 回答与 Markdown 来源支持导出 MD、PDF、DOCX；表格来源支持 CSV、XLSX。模型也可通过 `save_artifact` 直接请求对应格式：报告传 Markdown，电子表格传 CSV，由本地编码器生成实际文件，不接受模型提供的 Base64 或伪二进制。Word 使用 DOCX、Excel 使用 XLSX，不支持旧 DOC/XLS。
- 报告支持基础标题、段落、列表、表格与链接文字；不下载并嵌入远程图片。PDF 离线嵌入随应用分发的 Noto Sans SC 字体，支持中文分页与重复表头。Word、Excel 使用阅读软件的字体替代；不承诺与 PDF 完全相同的版式。
- 单次源内容最多 120000 UTF-8 字节，单个编码文件最多 20 MB；PDF 最多 100 页，报告表格最多 12 列；XLSX 最多 2000 行、50 列，超高单元格需拆成多行。编码在独立 isolate 中完成。XLSX 保留数值类型、前导零文本与换行，不执行模型提供的公式；CSV 继续中和公式前缀。
- 手机分享会在任务私有目录生成保留原文件名的副本，再交给系统分享，避免接收应用显示内部数字/哈希文件名。桌面成果文件右侧使用「打开所在文件夹」按钮：macOS/Windows 定位同名副本，Linux 打开副本所在目录；失败时显示错误。独立的「导出结果」在桌面继续使用另存为。
- 文件记录保留不可变的 Markdown/CSV 来源快照，二进制预览和重新导出使用此快照；旧版 MD/CSV 文件仍可直接读取。来源和临时导出副本都保存在任务私有目录，删除任务、关联对话或清空数据时一起清理。三项功能均不增加 MCP、插件安装或多 Agent 调度。

## 范围

- 单 Agent、多轮工具调用，支持 OpenAI 兼容 Chat Completions 和 Claude Messages。每轮使用完整非流式结果，截断或无效参数不会执行；兼容服务是否支持需实际核验。
- 工具：默认服务网页搜索、公开 HTTPS 网页正文读取、所选项目知识检索、按文档 ID 分页读取、生成 Markdown、PDF、Word（DOCX）、CSV、Excel（XLSX）文件。
- 网页读取最多 3 次跳转、1 MB UTF-8 响应、10000 字符正文，仅接受 HTTPS 默认端口。DNS 结果经地址检查后直接连接已检查 IP；拒绝本机、私网、链路本地和受限地址；不执行脚本，不处理登录。使用将公网域名映射到保留地址的 Fake-IP DNS/代理时也会拒绝读取，不自动绕过。
- 项目读取在数据库查询中检查项目归属。工具参数逐项校验，未知工具拒绝执行。不提供 shell、SQL、外部文件覆盖、邮件发送、MCP 或定时任务。
- 最终回答直接落入原聊天，保留任务多次执行累计的耗时和项目资料快照；非流式请求不记录首 Token 耗时，旧任务未记录的耗时保留为空；有文件交付要求时由 `save_artifact` 创建。旧版独立任务仍保留自动生成 `report.md` 的恢复行为。CSV 解析引号和换行，并转义可能触发电子表格公式的单元格。
- 执行过程、工具结果和来源可检查；来源清单只代表实际提供的资料，不代表自动逐项事实核验。

## 聊天内处理过程

- 执行中自动显示最近三条已开始或结束的工具步骤，包括实际搜索词、公开网页域名、文档名、文件名，以及工具实际返回的资料条数或提取字数；可展开全部步骤，待执行调用明确标为待执行。完成后默认收起过程，原「执行记录」保留参数、结果与诊断。
- 当前模型回合未返回时显示「等待模型回答」与轮次，继续更新本次执行的耗时；阶段变化和工具结果复用现有执行事件，不新增模型请求，不构造百分比或虚假的思考文本。当前工具接口仍为非流式回合，不逐字展示模型内部推理。
- Agent 执行时将耗时合并进卡片，隐藏重复的普通加载气泡；已有模型公开文字仍可显示。暂停、失败、未执行分别标明，不当成完成。
- 功能小字位于输入框下方、输入条内部，与文本框左侧对齐；仅显示当前开启的功能，全部关闭不占额外高度，与输入框共用 SafeArea 并随键盘上移。

## 执行与恢复

每次执行最多 12 轮模型请求、24 次工具尝试（包含失败和重试）、5 分钟。累计请求数不再阻止手动继续；达到次数前尽量保留一轮停用工具的阶段回答；单轮工具调用超出剩余额度时，对剩余调用写入配对的未执行结果，再进入阶段回答，重复相同调用或连续工具失败也会提前收尾。工具超时 40 秒；初始模型输出预留随窗口取 4K–16K，截断后在窗口允许范围内最多增至 64K，最多自动重试两次。Agent 的上下文预算独立于普通聊天，保存为 `agent_context_window_tokens`，默认 32K，最高可选 1M（1,048,576），可在管理页单独设置。估算包含提示词、历史、工具定义和结果；附件按估算 Token 计入，不把 Base64 当普通文本计数。超限先缩短请求副本的工具正文摘录，再省略较早的完整聊天轮次，保留当前任务的调用/结果关系、参数与协议签名。完整工具结果和聊天历史不被改写；仍超限时暂停，提供 Agent 专用调节入口。本地预算检查失败不消耗请求轮次，服务端实际限制仍可能不同。

切换聊天或关闭 Agent 会暂停；查看当前任务详情或设置可继续执行。息屏和离开应用不暂停。Android 使用普通应用进程执行，不启动前台服务、不请求前台服务或通知权限、不显示运行通知；系统允许时可在后台继续，系统挂起时随进程挂起，不保证息屏或后台持续执行。划掉应用销毁引擎或系统回收进程后，保留已落盘检查点，需手动继续。iOS 用 `beginBackgroundTask` 申请额外执行时间，系统收回时间后进程可能被挂起，回到前台后尝试继续；5 分钟按本次执行经过的时间计算，包含挂起时间，恢复后可能因本次时限或请求超时暂停，需要手动继续。系统终止进程后也需手动继续。桌面进程在锁屏后继续执行。任务从详情页手动继续后，返回也继续运行，运行结束后释放执行器。手动暂停不会撤回已经落盘的文件。只有显式继续才重新执行被暂停的任务。当前未完成任务可直接在输入框发送“继续”，会恢复原检查点，不再重复插入用户消息；已交付阶段回答后的继续提问作为新一轮任务。

任务 JSON 以 `agent_task:<UUID>` 保存到已有 SQLite `settings` 表，无需升版或重建旧数据库。保存调用意图、待完成调用及每个结果；恢复跳过已确认完成的步骤。公开读取可重新尝试；文件按任务和步骤确定路径，重复执行覆盖同一个应用自有文件，不重复创建。关联任务记录当前对话和用户消息 ID，完成时在同一事务内写入助手回复并保存其 ID；重复保存不重复插入回复。对话被删除、移至其它项目或已有更新消息时拒绝继续未交付的任务。旧版任务最终回答已保存时可只补交付文件，避免再次请求模型。

真实文件位于应用私有 `chat_attachments/agent_artifacts/<任务 UUID>/`。普通附件孤儿清理忽略该子目录；删除任务或关联对话删除对应目录，清空本地数据同时删除任务记录和文件。用户导出到应用外的副本由用户自行管理。

任务不自动写入长期记忆，项目与全局记忆的原规则不变。开始时快照当前提示词；任务目标和资料只发给所选模型，搜索词发默认搜索服务，网页请求直连网站。所有记录和成果为本机明文；模型及搜索凭据仅由各适配器从安全存储读取，不成为工具参数。

## 诊断与设计参考

执行记录可查看每次模型请求的停止原因、输出上限、HTTP 状态和已报告用量；截断、空输出、服务中断、协议错误不再合并成“不支持工具调用”。无效工具参数会回传关联错误供模型修正，不执行不完整的调用。请求重试等待可取消。Debug 构建把同一次运行的开始、模型回合、工具结果和结束打到控制台，只含任务编号、模型、状态码、用量和耗时，不含目标、参数、回复、原始响应或密钥。开源源码对照及保留的边界见 [核心逻辑对照](AGENT_ENGINE_REVIEW.md)。

输入框下方用小字显示已打开的联网搜索、可用自动朗读、Agent 和当前对话正在使用的全局记忆；每个图标与文字垂直居中，窄屏自动换行。联网搜索关闭后不再显示，Agent 也不再搜索。跨会话记忆总开关打开、且当前对话的单独选择或默认使用开关允许时，普通对话显示「全局记忆」并附带资料；这条对话在消息设置里单独关闭，或当前是项目对话时不显示。全部关闭不占空间。

## 内部结构与新增工具

- `lib/agent/agent_runner.dart` 负责模型回合、额度、任务保存和暂停恢复；工具的网络资源取消统一委托给执行器。
- `lib/agent/agent_tools.dart` 的固定注册表负责工具名称、参数定义、显示文案、执行方法及可用条件。模型收到的工具清单和实际分发共用此表；执行时仍校验必填项、未知参数、项目范围和搜索开关。
- `lib/agent/agent_presentation.dart` 保存状态与恢复分类，`agent_task_actions.dart` 保存共用恢复组件；页面负责导航，工具名称从注册表取译文。

新增返回 JSON 结果的内置工具时：

1. 在 `agent_tools.dart` 实现处理器，明确参数类型、长度、权限和副作用范围。异步读取后调用 `check()`，再写入来源或任务状态；新增可取消资源须纳入执行器的 `cancel()`。
2. 在 `agentToolRegistry` 增加一项，包括参数、必填项、显示文案 key、执行方法和可用条件；项目工具使用 `requiresProject`，搜索工具使用 `requiresSearch`。资料归属与凭据校验仍在实际执行时完成。
3. 新文案同时补齐三种语言；在 `test/agent_tools_test.dart` 补参数、权限及取消等边界用例，并运行 Agent 相关测试。通常无需修改执行循环或两种协议适配器。

本轮保留现有单 Agent、单任务执行方式，未增加插件安装、Agent 类型选择或多 Agent 调度；任务 JSON、工具名称、调用关联、成果文件路径和已有操作方式保持兼容。
