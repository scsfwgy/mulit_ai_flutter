# Agent 首版

2026-10-31 实现。默认关闭，在「设置 → Agent → 开启 Agent」开启；开启后聊天输入区上方出现「执行任务」。普通聊天与手表问答沿用原有流程。

## 使用

1. 配置支持工具调用的文字模型；需要搜索时配置默认搜索服务。
2. 进入「执行任务」，选择模型、可选项目，输入目标和交付要求。来自聊天页时默认沿用当前模型与项目。
3. 查看任务状态、执行记录、实际提供给模型的来源和成果文件。Markdown 可预览，CSV 可查看原文；手机分享、桌面选择保存位置。
4. 暂停或离开任务页后，可从任务记录手动继续。关闭 Agent 会暂停正在运行的任务，保留记录和文件；关闭时只能查看，不能执行。

模型使用当前服务的 API Key 直连；每项任务只使用所选服务与模型。服务被删除、更换地址或协议后拒绝继续旧任务，防止将旧资料默默发送到新服务。需要可用的应用购买/试用权限（适用平台）。

## 范围

- 单 Agent、多轮工具调用，支持 OpenAI 兼容 Chat Completions 和 Claude Messages。每轮使用完整非流式结果，截断或无效参数不会执行；兼容服务是否支持需实际核验。
- 工具：默认服务网页搜索、公开 HTTPS 网页正文读取、所选项目知识检索、按文档 ID 分页读取、生成 Markdown/CSV 文件。
- 网页读取最多 3 次跳转、1 MB UTF-8 响应、10000 字符正文，仅接受 HTTPS 默认端口。DNS 结果经地址检查后直接连接已检查 IP；拒绝本机、私网、链路本地和受限地址；不执行脚本，不处理登录。使用将公网域名映射到保留地址的 Fake-IP DNS/代理时也会拒绝读取，不自动绕过。
- 项目读取在数据库查询中检查项目归属。工具参数逐项校验，未知工具拒绝执行。不提供 shell、SQL、外部文件覆盖、邮件发送、MCP 或定时任务。
- 最终回答自动生成 `report.md`，附加实际来源清单；额外文件由 `save_artifact` 创建。CSV 解析引号和换行，并转义可能触发电子表格公式的单元格。
- 执行过程、工具结果和来源可检查；来源清单只代表实际提供的资料，不代表自动逐项事实核验。

## 执行与恢复

每任务最多 12 轮模型请求、24 次工具尝试（包含失败和恢复重试），每次执行最多 5 分钟。工具超时 40 秒，模型输出预留 4096 Token。上下文预算按当前设置粗估，包含完整工具定义和结果；超限会停止，不自动丢弃工具调用关系。

离开任务详情、应用进入后台、关闭 Agent 均请求暂停；不承诺后台续跑。当前步骤可能已经完成，暂停不会撤回已经落盘的文件。只有显式继续才重新执行。

任务 JSON 以 `agent_task:<UUID>` 保存到已有 SQLite `settings` 表，无需升版或重建旧数据库。保存调用意图、待完成调用及每个结果；恢复跳过已确认完成的步骤。公开读取可重新尝试；文件按任务和步骤确定路径，重复执行覆盖同一个应用自有文件，不重复创建。最终回答已保存时可只补交付文件，避免再次请求模型。

真实文件位于应用私有 `chat_attachments/agent_artifacts/<任务 UUID>/`。普通附件孤儿清理忽略该子目录；删除任务删除对应目录，清空本地数据同时删除任务记录和文件。用户导出到应用外的副本由用户自行管理。

任务不自动写入长期记忆，项目与全局记忆的原规则不变。开始时快照当前提示词；任务目标和资料只发给所选模型，搜索词发默认搜索服务，网页请求直连网站。所有记录和成果为本机明文；模型及搜索凭据仅由各适配器从安全存储读取，不成为工具参数。
