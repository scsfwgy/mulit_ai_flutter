# Agent 首版

2026-10-31 实现并调整为聊天内执行。默认关闭，在「设置 → Agent → 开启 Agent」开启；「更多 → 消息设置」显示状态，点击直接进入管理页。开启后手机/桌面聊天直接执行 Agent 任务；关闭时恢复普通聊天，手表问答沿用原有流程。

## 使用

1. 配置支持工具调用的文字模型；需要搜索时配置默认搜索服务。
2. 在当前聊天输入任务，直接沿用当前模型、项目、提示词与按预算选择的聊天历史；附件沿用普通聊天的协议发送。
3. 在原对话查看回复、执行卡片、执行记录、来源与请求生成的文件。Markdown 可预览，CSV 可查看原文；手机分享、桌面选择保存位置。
4. 暂停后，可从原对话执行卡片或任务记录手动继续。关闭 Agent 会暂停正在运行的任务，保留记录和文件；关闭时只能查看，不能执行。

模型使用当前服务的 API Key 直连；每项任务只使用所选服务与模型。服务被删除、更换地址或协议后拒绝继续旧任务，防止将旧资料默默发送到新服务。需要可用的应用购买/试用权限（适用平台）。

## 范围

- 单 Agent、多轮工具调用，支持 OpenAI 兼容 Chat Completions 和 Claude Messages。每轮使用完整非流式结果，截断或无效参数不会执行；兼容服务是否支持需实际核验。
- 工具：默认服务网页搜索、公开 HTTPS 网页正文读取、所选项目知识检索、按文档 ID 分页读取、生成 Markdown/CSV 文件。
- 网页读取最多 3 次跳转、1 MB UTF-8 响应、10000 字符正文，仅接受 HTTPS 默认端口。DNS 结果经地址检查后直接连接已检查 IP；拒绝本机、私网、链路本地和受限地址；不执行脚本，不处理登录。使用将公网域名映射到保留地址的 Fake-IP DNS/代理时也会拒绝读取，不自动绕过。
- 项目读取在数据库查询中检查项目归属。工具参数逐项校验，未知工具拒绝执行。不提供 shell、SQL、外部文件覆盖、邮件发送、MCP 或定时任务。
- 最终回答直接落入原聊天；有文件交付要求时由 `save_artifact` 创建。旧版独立任务仍保留自动生成 `report.md` 的恢复行为。CSV 解析引号和换行，并转义可能触发电子表格公式的单元格。
- 执行过程、工具结果和来源可检查；来源清单只代表实际提供的资料，不代表自动逐项事实核验。

## 执行与恢复

每次执行最多 12 轮模型请求、24 次工具尝试（包含失败和重试）、5 分钟。累计请求数不再阻止手动继续；达到次数前尽量保留一轮停用工具的阶段回答，重复相同调用或连续工具失败也会提前收尾。工具超时 40 秒；初始模型输出预留随窗口取 4K–16K，截断后在窗口允许范围内最多增至 64K，最多自动重试两次。Agent 的上下文预算独立于普通聊天，保存为 `agent_context_window_tokens`，默认 32K，最高可选 1M（1,048,576），可在管理页单独设置。估算包含提示词、历史、工具定义和结果；附件按估算 Token 计入，不把 Base64 当普通文本计数。超限先缩短请求副本的工具正文摘录，再省略较早的完整聊天轮次，保留当前任务的调用/结果关系、参数与协议签名。完整工具结果和聊天历史不被改写；仍超限时暂停，提供 Agent 专用调节入口。本地预算检查失败不消耗请求轮次，服务端实际限制仍可能不同。

切换聊天或关闭 Agent 会暂停；查看当前任务详情或设置可继续执行。息屏和离开应用不暂停。Android 在执行期间启动数据同步前台服务并显示「Agent 正在执行」，避免锁屏后进程被冻结；划掉应用会销毁引擎并暂停。iOS 用 `beginBackgroundTask` 申请额外执行时间，系统收回时间后进程可能被挂起，重新打开应用后从原进度继续，不因此记成暂停。桌面进程在锁屏后继续执行。旧版独立任务在离开详情时不再因进入后台而暂停。手动暂停不会撤回已经落盘的文件。只有显式继续才重新执行被暂停的任务。当前未完成任务可直接在输入框发送“继续”，会恢复原检查点，不再重复插入用户消息；已交付阶段回答后的继续提问作为新一轮任务。

任务 JSON 以 `agent_task:<UUID>` 保存到已有 SQLite `settings` 表，无需升版或重建旧数据库。保存调用意图、待完成调用及每个结果；恢复跳过已确认完成的步骤。公开读取可重新尝试；文件按任务和步骤确定路径，重复执行覆盖同一个应用自有文件，不重复创建。关联任务记录当前对话和用户消息 ID，完成时在同一事务内写入助手回复并保存其 ID；重复保存不重复插入回复。对话被删除、移至其它项目或已有更新消息时拒绝继续未交付的任务。旧版任务最终回答已保存时可只补交付文件，避免再次请求模型。

真实文件位于应用私有 `chat_attachments/agent_artifacts/<任务 UUID>/`。普通附件孤儿清理忽略该子目录；删除任务或关联对话删除对应目录，清空本地数据同时删除任务记录和文件。用户导出到应用外的副本由用户自行管理。

任务不自动写入长期记忆，项目与全局记忆的原规则不变。开始时快照当前提示词；任务目标和资料只发给所选模型，搜索词发默认搜索服务，网页请求直连网站。所有记录和成果为本机明文；模型及搜索凭据仅由各适配器从安全存储读取，不成为工具参数。

## 诊断与设计参考

执行记录可查看每次模型请求的停止原因、输出上限、HTTP 状态和已报告用量；截断、空输出、服务中断、协议错误不再合并成“不支持工具调用”。无效工具参数会回传关联错误供模型修正，不执行不完整的调用。请求重试等待可取消。Debug 构建把同一次运行的开始、模型回合、工具结果和结束打到控制台，只含任务编号、模型、状态码、用量和耗时，不含目标、参数、回复、原始响应或密钥。开源源码对照及保留的边界见 [核心逻辑对照](AGENT_ENGINE_REVIEW.md)。

输入框上方仅用一行小字显示已打开的联网搜索、可用自动朗读、Agent 和当前对话正在使用的全局记忆；图标与文字同一行居中。联网搜索关闭后不再显示，Agent 也不再搜索。跨会话记忆的总开关打开后，普通对话显示「全局记忆」并附带资料；这条对话在消息设置里单独关闭，或当前是项目对话时不显示。全部关闭不占空间。
